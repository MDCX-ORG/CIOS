MDCX Design Language

One language for every MDCX surface: the marketing site (Stage) and the CIOS portals (Console). Mono base, one signal — X Blue, rationed the way the logo rations it. This page demos itself: flip the theme toggle; everything survives both themes because it only uses tokens.

1.2 The X principle (accent rationing)

Per view region, at most one X Blue moment. The primary CTA on a marketing section · the active nav item in the console · the selected node on a canvas. Everything else is mono ink. X Blue is never body text, borders-at-rest, large backgrounds, decoration, or a status color.

2Principles

1 · Mono base, one signal. Near-black and white carry the brand; X Blue is rationed per §1.2. If everything is highlighted, nothing is.

2 · Two surfaces, one language. Stage (marketing/investor): dark, cinematic, editorial, 2px. Console (CIOS portals): light-default + dark, dense, calm, 6px. Same palette, type, voice, status system.

3 · Engineering truth. Real numbers beat adjectives ("1,240 kW", not "powerful"). Identifiers are monospace, always: sgp01.pod002.cdu000.fws.supply.flow. State is honest — real upstream errors, Roadmap labels on unshipped capability, async lifecycles instead of bare spinners.

4 · Token-only color. Every color resolves to a §3 token. Raw palette classes and hex literals in page code are forbidden in both repos.

5 · Dense but calm. Consoles show one screen of high-density truth; density comes from a consistent scale, not ad-hoc shrinking. Stage shows one idea per viewport.

6 · Sharp geometry. Chamfered, near-sharp corners echo the wordmark. Nothing pill-shaped except status pills. No blobs, no large radii, no glassmorphism.

ok#22C55E · #15803D
warn#EAB308 · #A16207
critical#EF4444 · #B91C1C

Thermal/metric palette for diagrams only: supply #7DD3FC · return #FB923C · flow #22D3EE · heat = critical · power = ink.

8Icons & data-viz

Stroke icons only (lucide or equivalent), 1.5px stroke, 16/20px grid, ink colors. No filled, duotone, or emoji icons in product UI — Stage emoji card icons (🏗️💧🌊) are grandfathered until the next solutions.html redesign, then replaced with stroke glyphs.

Charts: mono greys for context series, X Blue for the series, status colors only for threshold breaches. Grid lines line-subtle, axis labels caption type, thermal palette per §3.3 for cooling diagrams.

9Voice & tone

Do
"≤6 months to revenue. 1,240 kW per block. ≥7 days offline autonomy."

"GPU-level telemetry — Roadmap"
Numbers first. Unshipped capability labeled.
Don't
"Blazingly fast time to market!"

"Industry-leading AI-powered autonomous operations."
Superlatives without numbers; aspirational present tense; exclamation marks.

Sentence case everywhere except eyebrows/table headers and product names (DC45, CIOS, MDCX). English on all surfaces. Error copy: outcome first, upstream detail verbatim, then the action.

10Accessibility

RequirementRule
ContrastAA: 4.5:1 body, 3:1 large text/UI — both themes. §3 pairs are pre-checked; don't tint below specified percentages.
Focus2px X Blue ring, 2px offset, on every interactive element. Never removed.
KeyboardAll CRUD keyboard-reachable; canvas ops mirrored in tables; Esc cancels modes.
Semanticsrole="alert|status" on feedback; aria-current="page" on active nav; labels wrap inputs; icon-only buttons get aria-label.
